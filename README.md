# Planet Dodger 🚀🪐

A 2D space survival game created for SWE 402 — Assignment 1,
based on the Unity Learn “2D Beginner Game: Sprite Flight” course.

## Play
[Play on Unity Play](https://play.unity.com/api/v1/games/game/c0566e83-6a0f-42b9-aada-b8d998be696e/build/latest/frame)

## How to Play
- Hold the left mouse button to steer and thrust toward the cursor.
- Avoid moving planets, obstacles, and the arena walls.
- Survive as long as possible to increase your score.
- Click Restart after a collision to try again.

## Features
- Randomized obstacle sizes, directions, and speeds
- Physics-based rocket movement and collisions
- Survival scoring with UI Toolkit
- Explosion effect and restart button
- WebGL browser build

## Customization and Bonus Features
- Imported planet sprites
- Ambient star particles
- Background music and explosion sound effects
- Animated booster flame that appears while thrusting

## Open the Project
1. Download or clone this repository.
2. In Unity Hub, add the project folder.
3. Open with Unity 6000.5.9f1.
4. Open Assets/Scenes/Game.unity and press Play.
